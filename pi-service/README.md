# Retired downloader service

This service is no longer used. Puffin downloads media entirely inside the desktop application on the user's computer, using its own local `yt-dlp` and FFmpeg engine. The website does not connect to this service, a Raspberry Pi, or Tailscale.

The files here are kept only as an archived reference for an older deployment. Do not install or run this service for the current Puffin desktop app. See the root [README](../README.md) for the current download and packaging architecture.
